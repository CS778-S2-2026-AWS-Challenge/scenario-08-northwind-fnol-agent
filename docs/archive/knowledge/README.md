# Retired synthetic knowledge corpus

The former policy sources and withdrawn manifest here are historical evidence only. They are not
registered, uploaded, ingested or retrieved by the current runtime. The current approved corpus is
registered in `config/knowledge-sources.json`.

The original source bytes are retained to preserve their recorded checksums and historical citation
provenance. Existing object-store objects and stored citations need not be deleted during upgrade;
the approved current manifest prevents superseded objects from entering new retrievals.
