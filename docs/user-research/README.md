# User Research

This directory contains the research evidence used to identify FNOL pain points, user needs, personas, and traceable prototype responses.

## Start Here

1. [FNOL Evidence Sheet](fnol-evidence-sheet.md) records the evidence, exact survey results, denominators, sources, and limitations.
2. [Pain Point Analysis](pain-point-analysis.md) synthesises the evidence into prioritised claimant and employee pain points.
3. [User Personas](user-personas.md) groups recurring goals, behaviours, and needs without treating the exploratory sample as population evidence.
4. [Research-to-Prototype Traceability](research-to-prototype-traceability.md) maps supported findings to prototype changes and validation boundaries.

Survey results are exploratory and must retain their question-specific denominators. Interview findings come from one consented insurance-industry participant and must not be generalised to all employees, insurers, or claims teams. Published operating evidence establishes context and mechanisms, not Northwind-specific prevalence or measured staff effort.
